The problem I solve

Most funnels don't break on the page. They break between the tools.

A form submits but the contact never gets tagged. A booking lands in the calendar but not the CRM. A replay goes to people who already bought. I look at the whole journey, not one page in isolation.

  • Data that doesn't arriveAnswers and lead sources that never reach the right CRM fields, so personalisation has nothing to work with.
  • Triggers that don't fireWorkflows waiting on a tag, field or form that was renamed, duplicated or never connected.
  • Follow-up that doesn't fitEveryone gets the same sequence, whether they attended, booked, bought or haven't started yet.

How I troubleshoot

Find the exact point where the journey breaks

A sample journey: "people opt in, but nobody gets the welcome email." Run the test to see how a step-by-step QA pass finds the cause.

  1. ·Form submits and shows the thank-you page
    landing page → form    not run
  2. ·Contact is created in the CRM
    form → CRM    not run
  3. ·Lead-magnet tag is applied
    CRM → tags    not run
  4. ·Contact enters the welcome workflow
    tag → workflow trigger    not run
  5. ·Welcome email arrives with the right link
    workflow → email    not run

Test one step at a time

Start where the person starts and follow the data. The first step that fails is where to look, and everything after it is a symptom.

Found at step 3

The contact arrives, but untagged

  1. The form was duplicated for a new campaign. The copy kept its fields but lost its apply tag action.
  2. The welcome workflow triggers on lead-magnet-guide, so it never starts.
  3. Fix: restore the tag action on the new form, then backfill the tag for contacts who opted in since the change.
All five steps pass

Journey restored

  1. New opt-ins are tagged and enter the workflow.
  2. Earlier opt-ins are backfilled, with a check that nobody receives the email twice.
  3. The fix is noted in the SOP so the next duplicated form includes the tag action.
